# How to put this project on your resume

**Be explicit that the data is simulated / public.** Recruiters and hiring managers will ask; saying it up front is fine
(the Cookie Cats dataset is a standard portfolio dataset). Do NOT claim impact figures as if from a real business.

## Project entry (Projects section)
**F2P Mobile Game Player Analytics (Python, SQL, scikit-learn, Looker Studio)**  |  GitHub link
- Designed and analysed an A/B test on 90k simulated mobile-game players (SRM check, power analysis, bootstrap CIs, guardrail metrics); recommended against shipping a later progression gate after it cut D7 retention by 1.5pp.
- Built SQL models for DAU, cohort retention (D1/D7/D30), funnel drop-off and ARPU/ARPPU; produced a KPI dashboard from the outputs.
- Compared naive vs interrupted-time-series pre/post estimates for a product change, showing the naive method overstated the lift.
- Segmented players with RFM + K-Means (whales, minnows, engaged, casual, churned) and recommended a distinct monetisation/LiveOps action per segment.
- Analysed a LiveOps event and soft-currency economy; identified coin hoarding among veteran players and proposed a late-game sink.
